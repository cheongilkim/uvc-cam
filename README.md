# UVC Cam for iPad (로키드 캠 UX 계승 · 외장 UVC 카메라 전용 PWA)

기존 안드로이드 기반 **로키드 캠(`rokid_cam_apps`)** 프로젝트의 실사용 UX(원터치 전체화면, 안경 측면 장착 회전 보정, `1080p` 독서·저발열 최적화, 마이크 소거, 앱 전환 시 자가 복구)를 계승하여, **iPadOS 17+에서 별도의 송출 앱(`sender.apk`) 없이 표준 USB UVC 카메라를 바로 띄울 수 있도록 제작한 홈 화면 웹앱(PWA)** 프로젝트입니다.

* **공식 영구 HTTPS 배포 주소:** **https://cheongilkim.github.io/uvc-cam/**

---

## 1. 바로 설치 및 실행 방법 (가장 간편 — 맥 서버·인증서 설정 불필요)

1. iPad **Safari**에서 아래 주소에 접속합니다.  
   **`https://cheongilkim.github.io/uvc-cam/`**
2. 카메라 권한 팝업이 뜨면 **허용**을 누릅니다.
3. Safari 상단 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**를 누르면 바탕화면에 **`UVC Cam`** 아이콘이 생성됩니다.
   - *(또는 화면 하단의 `앱설치` 버튼으로 프로파일을 받아 설정에서 설치할 수도 있습니다.)*
4. iPad USB-C 포트에 **외장 UVC 카메라**를 꽂고 홈 화면의 **`UVC Cam`** 아이콘을 실행하면 즉시 전체화면으로 뜹니다.
   - 공인 HTTPS + Service Worker 오프라인 캐시가 적용되어 있어 **맥을 꺼두거나 밖에서도 7일 만료 없이 영구 사용 가능**합니다.

## 2. 기존 로키드 프로젝트(`rokid_cam_apps`)와의 차이점

| 구분 | 기존 로키드 캠 (`rokid_cam_apps`) | 이번 iPad용 UVC Cam (`uvc_cam_ipad`) |
| :--- | :--- | :--- |
| **카메라 입력 장치** | 로키드 AI 글래스 (Android 12 기기) | **일반 외장 USB UVC 카메라** (자체 OS 없음) |
| **연결 프로토콜** | 커스텀 USB Host ADB + TCP `18080` (`sender.apk` ↔ `viewer.apk`) | **iPadOS 17+ 표준 USB UVC (`getUserMedia` / `enumerateDevices`)** |
| **수신 기기** | 갤럭시(Android) / Mac (`scrcpy`) | **iPad (iPadOS 17 이상, USB-C 직결)** |
| **빌드 및 서명** | Android SDK / `apksigner`로 APK 빌드 | **Xcode 서명(7일 만료) 불필요** — GitHub Pages 공식 HTTPS + PWA |
| **계승한 UX 기능** | 원터치 전체화면, `270°` 회전, `1080p` 독서·저발열, 마이크 소거, 화면 전환 복구 | 동일 UX + **외장 UVC 자동 우선 감지**, **PIP/Split View**, **실시간 FPS·해상도 표시** |

## 3. 핵심 기능

1. **외장 UVC 카메라 자동 감지 및 우선 연결 (`Auto-Detect External UVC`)**
   - `Front`, `Back`, `TrueDepth`, `Ultra Wide`, `Desk View` 등 iPad 내장 카메라를 걸러내고 **외장 USB UVC 카메라를 최우선으로 자동 선택**합니다.
   - 앱을 켜둔 상태에서 USB-C UVC 카메라를 나중에 꽂거나 뺐다 다시 꽂아도 `devicechange` 이벤트를 감지해 자동으로 UVC 카메라로 전환됩니다.
2. **원터치 클린 전체화면 & 터치로 HUD 숨김 (`Tap-to-Hide HUD`)**
   - 화면 가운데를 한 번 터치하면 상단 상태 바·하단 제어 버튼이 모두 사라지고 순수 카메라 영상만 전체화면으로 출력됩니다. (제미나이 라이브 화면 공유 시 방해 요소 제거)
3. **안경 측면 장착 대응 회전(`0° / 90° / 180° / 270°`) 및 자동 스케일 보정**
   - 안경다리에 측면 장착 시 영상이 90° 돌아가 있어도 버튼 한 번으로 정방향 회전(`270°` 등)이 가능하며, `90°`/`270°` 회전 시 화면 잘림 없이 비율(`전체보기` / `꽉채우기`)을 자동 계산합니다. 좌우 반전과 함께 설정값이 자동 저장됩니다.
4. **독서·OCR 가독성 + 저발열 프리셋**
   - **기본값:** `1080p 독서·저발열 (10fps)` — 책 글자가 선명하게 보이면서도 발열과 배터리를 아끼는 모드
   - **전환 가능:** `4K 초고화질 (2160p)`, `1080p 부드럽게 (30fps)`, `720p 초저발열 (30fps)`
5. **UVC 마이크 입력 간섭 차단 (`audio: false`, `muted`)**
   - 비디오만 단독으로 열어 UVC 카메라에 달린 저품질 마이크가 제미나이 라이브의 iPad 마이크 입력을 가로채지 않도록 했습니다.
6. **앱 전환 시 무중단 자가 치유(Self-healing) + 화면 꺼짐 방지 + PIP**
   - 제미나이 앱과 오갈 때 카메라 스트림이 멈추거나 끊기면 2초 주기 Watchdog과 `visibilitychange` 감지가 자동으로 카메라 세션을 재연결합니다.
   - Screen Wake Lock으로 사용 중 화면이 꺼지지 않으며, `PIP` 버튼으로 작은 플로팅 창으로도 띄울 수 있습니다.

## 4. Gemini Live(제미나이 라이브) 활용 팁

1. iPad에 **외장 UVC 카메라(USB-C)**를 꽂고 **`UVC Cam`**을 실행합니다.
2. 화면을 터치해 메뉴를 숨긴 뒤, 두 가지 중 편한 방식으로 제미나이 라이브에 보여줍니다:
   - **전체화면 화면 공유:** Gemini 앱에서 **Gemini Live → 화면 공유**를 켠 뒤 `UVC Cam` 앱으로 전환하면 1인칭 안경 카메라 화면이 그대로 제미나이에게 전달됩니다.
   - **Split View (화면 분할):** iPad 상단 `...` 버튼으로 `UVC Cam`과 `Gemini`를 좌우로 나란히 두고 화면 공유를 켜면 앱 전환 없이 대화할 수 있습니다.
